Double Dragon II Recompiled
===========================

1. Keep every file in this folder together (dd2recomp.exe needs the .dll
   files and the assets folder beside it).
2. Double-click dd2recomp.exe.
3. The first time, pick your ROM of
   Double Dragon II - The Revenge (USA) (Rev 1). It is checked before the
   game starts. No game data is included in this download.

Settings (config.ini) and save states (saves\) are kept in this folder.

Escape or the right shoulder button opens the menu. F11 fullscreen,
F7 save states, F8 rewind, Tab fast forward.

Project page, recommended settings and source code:
https://github.com/gabbycat4/DD2Recomp
