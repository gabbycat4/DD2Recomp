## Download and play

You need your own dump of **Double Dragon II - The Revenge (USA) (Rev 1)**.
These downloads contain no game data; the game asks for your ROM the first
time it starts and checks that it is the right one.

### Windows
1. Download **DD2Recomp-Windows-x64.zip** and extract it anywhere (right-click,
   *Extract All*). Don't run it from inside the zip.
2. Double-click **dd2recomp.exe**. If Windows SmartScreen warns about an
   unknown publisher, click *More info*, then *Run anyway*.
3. Pick your ROM when asked. Settings and saves are kept in the same folder.

### Linux
1. Download **DD2Recomp-x86_64.AppImage**.
2. Make it executable: right-click, *Properties*, *Permissions*, tick
   *Allow executing as program* (or `chmod +x DD2Recomp-x86_64.AppImage`).
3. Double-click it and pick your ROM when asked. Settings and saves are kept
   in `~/.local/share/DD2Recomp`.

If the AppImage won't start on an older distribution, install FUSE 2
(`sudo apt install libfuse2` on Ubuntu/Debian), or run it with
`--appimage-extract-and-run`.

### Controls
Escape (or the right shoulder button) opens the menu. F11 fullscreen,
F7 save states, F8 rewind, Tab fast forward. The README has the recommended
settings for high-refresh monitors.
